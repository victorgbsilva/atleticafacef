# AAA XX-Março

Site institucional responsivo da atlética AAA XX-Março, com equipes, eventos, galeria de fotos e contato.

## Abrir no VS Code

1. Extraia `xx-marco-site.zip`.
2. No VS Code, use **Arquivo → Abrir Pasta** e selecione `xx-marco-site`.
3. Abra `index.html` no navegador. Se tiver a extensão Live Server, clique em **Go Live** para visualizar alterações enquanto edita.

A página `quem-somos.html` contém a apresentação da atlética. Os estilos, scripts e imagens são compartilhados pelas duas páginas e usam caminhos relativos.

Esta versão usa HTML, CSS e JavaScript. React ainda não está configurado no projeto.
